# Security policy

## Supported versions

We currently support the latest minor release on the default branch. Security fixes are applied there first.

## Reporting a vulnerability

Please report security issues privately rather than using public GitHub issues.

- Open a [GitHub Security Advisory](https://github.com/fraware/universal-recycle/security/advisories/new) for this repository, if enabled for the project, **or**
- Email the maintainers at the contact address listed in the repository README under Support.

Include enough detail to reproduce the problem (version, configuration, and impact) so we can triage quickly.

## Disclosure

We will acknowledge receipt of your report and work on a fix. We ask that you allow a reasonable time for a patch before public disclosure.
